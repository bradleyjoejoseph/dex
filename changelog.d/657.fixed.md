**`transform rename` / `transform remove` honor Python and YAML snapshot readers.** A `dbt.ref()` / `dbt.source()` in a Python model, or a dbt 1.9 snapshot `relation:`, now blocks a removal the way a Jinja `ref()` does. Renaming a model updates a static YAML `relation:`; a Python reader on the old name refuses the rename unless the same plan updates or removes it (`--edits-file`).
