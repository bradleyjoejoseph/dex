**`DexEngine` returns typed host models from transform results.** `engine.build().evidence`, `engine.classify().classifications`, `engine.ground().grounding`, and `engine.export_plan().plan` return typed host models (`BuildEvidence`, `ArtifactClassification`, `Grounding`, `PortablePlan`) rather than plain dictionaries, with backwards-compatible subscripting (`item["key"]`), `.get()`, and `in` operator support, as well as typed accessor methods (`.evidence_model()`, `.classification_models()`, `.grounding_model()`, `.plan_model()`).
